Sistema web em Flask com Oracle para processar o programa de Cashback Progressivo usando cursor explícito em bloco anônimo PL/SQL.

Regras de negócio

  • Processar somente inscrições com status PRESENT.
  • Contar presenças do usuário dentro do loop do cursor.
  • Aplicar 25% se o usuário tiver mais de 3 presenças.
  • Aplicar 20% se a inscrição for VIP.
  • Aplicar 10% nos demais casos.
  • Atualizar o saldo em USUARIOS e registrar em LOG_AUDITORIA.
